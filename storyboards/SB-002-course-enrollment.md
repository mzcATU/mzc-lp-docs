# SB-002: 강의 탐색 및 수강 신청

## 1. 화면 플로우

```
[대시보드]
    → [강의 카탈로그]
    → [강의 상세]
    → [차수 선택]
    → [수강 신청 확인]
    → [결제] (유료인 경우)
    → [신청 완료]
    → [내 강의실]
```

- 공유하기
- 차수별 수강 신청

**API 호출:**
```typescript

```
┌─────────────────────────────────────────┐
│  수강 신청                        [X]   │

│                                         │

│  가격: 50,000원                          │
│                                         │
│  ┌────────────────────────────────┐   │
│  │  신청 방식: 자동 승인             │   │
│  │  - 신청 즉시 수강이 시작됩니다    │   │
│  └────────────────────────────────┘   │
│                                         │
│  □ 취소 및 환불 정책에 동의합니다       │
│                                         │
│  ┌──────────┐  ┌──────────┐          │

- **초대 전용**: 관리자 초대로만 수강 가능

## 3. 상태별 UI 변화

### 3.1 수강 신청 버튼 상태

| 상태 | 버튼 텍스트 | 색상 | 활성화 |
|------|-------------|------|--------|
| 신청 가능 | 수강 신청 | Primary (파란색) | O |
| 정원 마감 | 정원 마감 | Disabled (회색) | X |
| 신청 기간 종료 | 신청 마감 | Disabled (회색) | X |
| 이미 신청 | 수강 중 | Success (초록색) | X |
| 승인 대기 | 승인 대기 중 | Warning (주황색) | X |

### 3.2 차수 카드 상태

**정원 표시:**
- 여유: "정원: 10/30명" (검은색)
- 마감 임박: "정원: 28/30명" (주황색)
- 마감: "정원: 30/30명" (빨간색)

**기간 표시:**
- 신청 대기: "신청 시작: 2026.01.15" (회색)
- 신청 가능: "2026.02.01 ~ 2026.03.31" (검은색)
- 진행 중: "진행 중 (D+15)" (초록색)
- 종료: "종료됨" (회색)

## 4. 사용자 인터랙션

### 4.1 찜하기
```
클릭 전: ♡ 찜하기
클릭 후: ♥ 찜 취소 (빨간색)
+ 토스트 메시지: "찜 목록에 추가되었습니다"
```

### 4.2 장바구니
```
클릭 시: 🛒 장바구니에 추가
+ 스낵바: "장바구니에 담았습니다" [장바구니 보기]
```

### 4.3 수강 신청 진행 중
```
로딩 스피너 + "수강 신청 처리 중..."
→ 완료 시 리다이렉트 또는 모달 표시
```

## 6. 반응형 디자인

### 모바일 (375px ~ 767px)
- 카탈로그: 1열 카드 레이아웃
- 필터: 하단 시트로 표시
- 강의 상세: 세로 스크롤
- 탭: 스와이프 가능

### 태블릿 (768px ~ 1024px)
- 카탈로그: 2열 카드 레이아웃
- 필터: 좌측 사이드바 (접을 수 있음)

### 데스크톱 (1025px ~)
- 카탈로그: 3~4열 카드 레이아웃
- 필터: 좌측 고정 사이드바

## 7. 접근성 (Accessibility)

- 모든 버튼에 aria-label 추가
- 키보드 네비게이션 지원
- 스크린 리더 지원
- 색맹 모드 고려 (색상만으로 정보 전달 금지)
- 최소 대비율 4.5:1 준수
