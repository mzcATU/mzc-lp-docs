## 3. 진도 관리

### 3.1 진도 계산 방식

**전체 진도율:**
```
전체 진도율 = (완료한 차시 수 / 전체 차시 수) × 100
```

**차시별 진도:**
- 비디오: 시청 비율 (0% ~ 100%)
- 문서: 열람 시간 기반
- 퀴즈: 제출 여부
- 과제: 제출 여부

### 3.2 완료 조건

**차시 완료:**
- 비디오: 설정된 % 이상 시청 (예: 80%)
- 문서: 설정된 시간 이상 열람 (예: 5분)
- 퀴즈: 통과 점수 이상 획득
- 과제: 제출 완료

**강의 수료:**
- 모든 필수 차시 완료
- 최소 출석률 달성 (설정된 경우)
- 최종 시험 통과 (설정된 경우)

## 6. API 호출 순서

```typescript
// 1. 수강 정보 및 커리큘럼 조회
GET /api/enrollments/{enrollmentId}
GET /api/learning/{enrollmentId}/curriculum

// 2. 차시 콘텐츠 로드
GET /api/learning/{enrollmentId}/items/{itemId}

// 3. 진도 업데이트 (주기적)
PUT /api/learning/{enrollmentId}/items/{itemId}/progress
{
  "progressRate": 36.7,
  "learningTime": 330,  // 초
  "lastPosition": 330   // 비디오인 경우
}

// 4. 차시 완료
PUT /api/learning/{enrollmentId}/items/{itemId}/complete

// 5. 퀴즈 제출
POST /api/learning/{enrollmentId}/quizzes/{quizId}/submit
{
  "answers": [
    { "questionId": 1, "answer": "2" },
    { "questionId": 2, "answer": "1" }
  ]
}

// 6. 과제 제출
POST /api/assignments/{assignmentId}/submissions
{
  "content": "설명...",
  "attachments": [File]
}

// 7. 전체 진도 조회
GET /api/learning/{enrollmentId}/progress
```

## 8. 성능 최적화

- 비디오: HLS/DASH 스트리밍
- 진도 저장: Debounce (10초)
- 콘텐츠 프리로딩: 다음 차시
- 이미지 레이지 로딩
- 커리큘럼: 가상 스크롤
