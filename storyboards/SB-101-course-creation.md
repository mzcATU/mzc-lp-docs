# SB-101: 강의 생성 및 편집

## 1. 화면 플로우

```
[강의 관리]
    → [새 강의 만들기]
    → [기본 정보 입력]
    → [임시 저장]
    → [커리큘럼 편집]
    → [미리보기]
    → [발행]
```

## 4. 강의 상태 관리

### 상태 전환
```
작성 중 → 발행됨 → 보관됨
   ↓        ↓
  삭제    수정(새 버전)
```

**상태별 UI:**
- 작성 중: 회색 배지
- 발행됨: 초록색 배지 + ✓
- 보관됨: 주황색 배지

## 6. API 호출 순서

```typescript
// 1. 강의 생성
POST /api/courses
{
  "title": "React 완벽 가이드",
  "categoryId": 5,
  "level": "INTERMEDIATE",
  ...
}

// 2. 차시 추가
POST /api/courses/{courseId}/items
{
  "title": "1-1. React 소개",
  "type": "VIDEO",
  "contentId": 123,
  "sortOrder": 1,
  "completionCriteria": {
    "type": "VIDEO_WATCH_RATE",
    "value": 80
  }
}

// 3. 차시 순서 변경
PUT /api/courses/{courseId}/items/reorder
{
  "items": [
    { "id": 1, "sortOrder": 1 },
    { "id": 2, "sortOrder": 2 }
  ]
}

// 4. 강의 발행
PUT /api/courses/{courseId}/publish
```

## 7. 반응형 디자인

### 모바일
- 탭을 하단 네비게이션으로 변경
- 커리큘럼 트리를 단순화
- 모달을 전체 화면으로 표시

### 태블릿
- 사이드 패널 접기/펼치기
- 드래그 앤 드롭 터치 지원
