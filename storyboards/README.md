## 화면 설계 원칙

### 반응형 디자인
- 데스크톱: 1920px 기준
- 태블릿: 768px ~ 1024px
- 모바일: 375px ~ 767px

### 색상 체계
- Primary: #1976d2 (파란색)
- Secondary: #dc004e (빨간색)
- Success: #4caf50 (초록색)
- Warning: #ff9800 (주황색)
- Error: #f44336 (빨간색)

### 타이포그래피
- 제목: Pretendard Bold 24px ~ 32px
- 본문: Pretendard Regular 14px ~ 16px
- 캡션: Pretendard Regular 12px

### 레이아웃 구조
```
┌─────────────────────────────────────────┐
│           Header (GNB)                  │
├─────────┬───────────────────────────────┤
│   LNB   │                               │
│  (메뉴) │         Main Content          │
│         │                               │
│         │                               │
└─────────┴───────────────────────────────┘
```
