# SB-302: UI 컴포넌트 가이드

## 1. 공통 컴포넌트

### 1.1 버튼 (Button)

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Primary    │  │  Secondary   │  │   Outlined   │
└──────────────┘  └──────────────┘  └──────────────┘

┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│     Text     │  │   Disabled   │  │ [🔍] Icon    │
└──────────────┘  └──────────────┘  └──────────────┘
```

**크기:**
- Small: 32px height
- Medium: 40px height (기본)
- Large: 48px height

**색상 (Primary):**
- Background: #1976d2
- Text: #ffffff
- Hover: #1565c0
- Active: #0d47a1
- Disabled: #e0e0e0

**사용 예:**
```typescript
<Button variant="primary" size="medium">
  수강 신청
</Button>

<Button variant="outlined" startIcon={<SearchIcon />}>
  검색
</Button>
```

### 1.3 입력 필드 (Input)

**텍스트 필드:**
```
┌──────────────────────────────┐
│ Label *                       │
├──────────────────────────────┤
│ Placeholder text...           │
└──────────────────────────────┘
  Helper text or error message
```

**상태:**
- Default: 회색 테두리
- Focus: 파란색 테두리
- Error: 빨간색 테두리
- Disabled: 회색 배경

**예시:**
```typescript
<TextField
  label="강의명"
  required
  placeholder="강의 제목을 입력하세요"
  helperText="최대 100자"
  error={errors.title}
/>
```

## 9. 애니메이션

## 10. 접근성 (Accessibility)

- 최소 대비율: 4.5:1

- ARIA 레이블 사용
- 스크린 리더 지원
