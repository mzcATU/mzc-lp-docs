# User Flows - MZC Learning Platform

## 개요
본 문서는 MZC 학습 플랫폼의 주요 사용자 흐름을 정의합니다.

## 사용자 역할
- **SYSTEM_ADMIN**: 시스템 전체 관리자
- **TENANT_ADMIN**: 테넌트 관리자
- **OPERATOR**: 운영자
- **DESIGNER**: 강의 설계자/개설자
- **INSTRUCTOR**: 강사
- **USER**: 학습자
