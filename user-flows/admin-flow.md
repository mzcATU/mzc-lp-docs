# Admin Flow (관리자 플로우)

> 역할: TENANT_ADMIN
> 작성일: 2026-01-22

---

## 개요

**TENANT_ADMIN(테넌트 관리자)**는 조직 내 LMS 시스템을 총괄 관리하는 역할입니다.

### 주요 책임
- 조직 내 사용자 및 부서 관리
- 강의 개설 승인 및 관리
- 강사 배정 및 역할 관리
- 시스템 설정 및 정책 관리
- 전체 통계 및 리포트 조회

### 권한 범위
- 테넌트 내 모든 데이터 조회 및 관리
- 사용자 등록, 수정, 삭제
- 역할 부여 및 변경
- 강의 승인/반려
- 시스템 설정 변경
- 전체 통계 및 감사 로그 조회

## 주요 API 엔드포인트

### 사용자 관리
```http
GET    /api/users                                # 사용자 목록
POST   /api/users                                # 사용자 등록
GET    /api/users/:id                            # 사용자 상세
PUT    /api/users/:id                            # 사용자 수정
DELETE /api/users/:id                            # 사용자 삭제
POST   /api/users/bulk-upload                    # 일괄 등록
PUT    /api/users/:id/roles                      # 역할 변경
PUT    /api/users/:id/status                     # 상태 변경
```

### 부서 관리
```http
GET    /api/departments                          # 부서 트리
POST   /api/departments                          # 부서 생성
PUT    /api/departments/:id                      # 부서 수정
DELETE /api/departments/:id                      # 부서 삭제
```

### 강의 승인
```http
GET    /api/programs?status=PENDING              # 승인 대기 목록
PUT    /api/programs/:id/approve                 # 승인
PUT    /api/programs/:id/reject                  # 반려
```

### 차수 관리
```http
GET    /api/course-times                         # 전체 차수 목록
GET    /api/course-times/:id                     # 차수 상세
PUT    /api/course-times/:id                     # 차수 수정
PUT    /api/course-times/:id/close               # 차수 종료
```

### 강사 배정
```http
GET    /api/course-times/:id/instructors         # 배정 현황
POST   /api/instructor-assignments               # 강사 배정

```

### 통계 및 리포트

## 권한 및 제약사항

### 할 수 있는 것
- ✅ 테넌트 내 모든 데이터 조회 및 관리
- ✅ 사용자 등록, 수정, 삭제, 역할 부여
- ✅ 부서 생성, 수정, 삭제
- ✅ 강의 개설 승인/반려
- ✅ 차수 생성, 수정, 종료
- ✅ 강사 배정 및 해제
- ✅ 시스템 설정 변경
- ✅ 모든 통계 및 리포트 조회
- ✅ 감사 로그 조회

### 할 수 없는 것
- ❌ 다른 테넌트 데이터 조회/수정
- ❌ 시스템 전역 설정 변경 (SYSTEM_ADMIN 권한 필요)
- ❌ 테넌트 생성/삭제 (SYSTEM_ADMIN 권한 필요)

## 주요 비즈니스 규칙

### BR-1: 사용자 삭제
- 수강 중인 강의가 있는 사용자는 삭제 불가
- 진행 중인 차수에 배정된 강사는 삭제 불가
- 소프트 삭제 적용 (실제 데이터는 보관)

### BR-2: 부서 삭제
- 하위 부서가 있는 경우 삭제 불가
- 소속 사용자가 있는 경우 삭제 불가

### BR-3: 강의 승인
- 커리큘럼이 완성된 강의만 승인 가능
- 승인 시 Snapshot 자동 생성
- 승인 취소 불가 (새로운 개설 신청 필요)

### BR-4: 차수 종료
- 종료 후에는 수정 불가
- 모든 평가가 완료되어야 종료 가능 (강제 종료 제외)
- 종료 시 수료증 자동 발급
